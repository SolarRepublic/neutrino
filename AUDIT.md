# Neutrino audit — 2026-10-07

Scope: all original source modules plus the added bounded SNIP-52 codec and diagnostics module, package/build/export configuration, existing tests, dependency advisories, and integration with the sibling `cosmos-grpc` checkout. This is a source review with targeted regression tests, not a formal cryptographic certification. No funded transactions or live contract executions were performed.

## Dependency and API migration

Neutrino now consumes `file:../cosmos-grpc`, targeting local commit `1229a42` (the package still declares `0.20.7`; that version alone does not identify these unreleased changes). Rebuild that checkout before installing Neutrino. The previous default artifact dated from September 2025 and did not include the source fixes. The default combined-chain schema is retained: the Secret-only preview lacks required auth/transaction endpoints and is explicitly experimental.

The new generator preserves exact timestamp/duration tuples, enforces oneof choices, merges singular message fragments, and changes maps to dictionaries. Neutrino does not directly pass temporal/map parameters; its signing code selects only the single-signature oneof. Regression checks exercise the freshly generated transaction API. These upstream API changes are breaking for downstream consumers using affected `cosmos-grpc` functions.

Direct runtime upgrades now include Belt 0.58.0 and Crypto 0.6.2, with local Contractor and Types. The coordinated Types/Contractor work repaired the initial Belt migration blockers. Targeted overrides select Belt 0.58 for Cosmos gRPC and Crypto, and local Types for Cosmos gRPC; their upstream manifests must adopt the tested versions before publication. The obsolete lint-config runtime override has been removed. Contractor, Solar Republic Types and ts-toolbelt are production dependencies because declarations refer to them. Removed obsolete Rollup/microweb, formatter, ts-node and WebSocket-polyfill tooling. Imports carry `.js` extensions directly.

ESM is now the single published implementation. The previous “cjs” build inherited `module: ES2022`, emitted ESM, and duplicated output without producing CommonJS. CommonJS consumers now use Node's synchronous `require(esm)` support (Node >=22.12); ESM browser usage is unchanged. This is a runtime-support change that needs release notes. Native TypeScript 7.0.2 now builds the project; tools use the TS6.0.3 API through the pinned 6.0.2 wrapper. TS5.9.3 remains a checked consumer floor. Source checks, emission comparison, ESLint and TypeDoc pass; see [UPGRADE_PLAN.md](UPGRADE_PLAN.md). Runtime tests and the clean package matrix pass on macOS arm64 with Node 22.12.0, in addition to Node 26.10.0 checks. Linux/Windows execution still needs validation; the later candidate pass exercises targeted crypto/WebSocket behavior in three real browser engines.

**Release blocker:** the sibling file dependency is for local development. Before publishing, assign the upstream breaking changes a distinct release version (or immutable distributable artifact), replace the local dependency, and validate a registry-clean consumer install. ## Fixed findings

| Severity | Finding | Change / regression coverage |
| --- | --- | --- |
| High | AES-SIV authentication failures included unauthenticated decrypted plaintext in exception messages, exposing private data to logs/telemetry. Flipping an IV-masked tag bit preserves the plaintext while failing authentication. | Wipe the temporary plaintext and return a generic authentication error; regression uses exactly that tag mutation. |
| High | ChaCha20 ignored key/nonce `byteOffset`, silently using unrelated bytes from backing buffers. | Offset-aware DataViews; OpenSSL differential tests across slices and block boundaries. Validate key/nonce lengths and reject counter overflow. |
| High | Contract metadata and code hashes were cached globally by address/code ID, mixing networks. Network caches also conflated custom clients without unique IDs. | WeakMap caches scoped to client identity; tests use identical code IDs/addresses on distinct clients. Reuse a client to reuse its cache. |
| Medium | Wallet fee defaults overrode explicit transaction fee arguments. Floating-point multiplication rounded large gas limits and could overcharge decimal prices. | Explicit arguments win, including zero; decimal price representation is multiplied using bigint with ceiling division. Invalid/unsafe numeric inputs fail. |
| Medium | Successful monitors left fallback timers running; thrown broadcasts leaked monitoring; failed socket setup could block fallback. | Teardown clears polling and listeners; broadcast errors clean up; socket setup failures fall back to LCD. Tests cover completion and thrown broadcasts. |
| Medium | WebSocket deadline ended at connection open, allowing an unacknowledged subscription to hang forever. Error/close paths leaked sockets/timers. | Deadline covers acknowledgement; all setup failures reject and close; tests cover timeout, close, error, malformed ack and numeric/string IDs. |
| Medium | Low-order consensus public keys could produce a publicly predictable all-zero ECDH secret. | SecretWasm rejects all-zero shared secrets and validates nonce length; temporary scalar is wiped. This does not authenticate the server's consensus key. |
| Medium | `test:all` executed only the first shell-expanded file, while the custom test helper logged failed assertions without failing CI. | Explicit offline suites run through Node's test runner; helper sets failing exit status. Live examples remain opt-in. |
| Medium | Published declaration dependencies were only dev dependencies; “CJS” output was not CommonJS. | Correct dependency/export metadata and native ESM imports; package-consumer smoke checks. |
| Medium | Live examples derived a publicly known private key from fixed demo text and used stale signing APIs. | Require explicit `NFP_PRIVATE_KEY_HEX` and update the examples; no live execution performed. |
| Low | Empty transaction data threw during response parsing; empty modern response arrays hid legacy entries. | Empty input yields an empty result list; legacy data is used when modern responses are empty. Higher-level helpers still need explicit missing-response handling. |

ChaCha20-Poly1305 now authenticates before decryption and compares all tag bytes without a secret-dependent early exit. JavaScript/JIT and BigInt implementations do not provide a constant-time guarantee.

## Follow-up repairs

- **SNIP-52 correctness/security:** counter-mode nonce derivation XORed the channel hash twice; fixed against the local SNIP-52 encryption specification and Node/OpenSSL-generated fixtures. Fixed bracketed array dimensions, nested schema parsing and SHA-512 bloom indices. Added payload/length/parameter/array/depth/work bounds, packet-length validation, a bounded definite-length CBOR parser (including exact uint64 and sliced buffers), serialized counter updates, same-transaction counter draining, and bounded replay suppression. Callback failures cannot prevent authenticated counter advancement. Removed the unsafe trivial CBOR decoder from this path. Unsubscribing an owned stream disposes its socket.
- **WebSocket lifecycle:** respect false restart decisions before reconnecting; attach event filters to shared handles; serialize filter dispatch and observe async callback failures. Added optional `listen()`/`dispose()` to managed handles, subscription cancellation, cancellation of pending reconnects, and listener snapshots so self-removal cannot skip peers. Legacy external handles without `listen()` attach only to their current raw socket. Reconnection currently makes one attempt per close and reports failure; configurable jittered retry/backfill remains future work.
- **Transaction lifecycle:** `expect_tx`/`broadcast_result` accept trailing `TxWaitOptions`, with a default total deadline of 120 seconds and AbortSignal. The deadline covers setup, broadcast and polling. `TxWaitError` retains the hash and reports inclusion as unknown. Scoped request signals cancel cooperative transports; the outer race also ends waits for noncooperating transports. Transient network/429/5xx polling failures use bounded backoff; a stalled broadcast response cannot hide observed inclusion. No automatic re-signing/re-broadcasting is performed.
- **Signer/account boundaries:** private keys are length/range checked and copied before the first await; WASM initialization shares an in-flight promise. Returned signers expose disposal, wipe owned key/entropy buffers, reject in-flight/future signing after disposal, and return public-key copies. `auth()` unwraps known base/module/vesting/Ethermint/Injective account forms and validates address and uint64 numbers; missing/unknown account data now rejects rather than silently signing with missing values. Metadata remains mutable and sequence coordination is not implemented.
- **Privacy:** removed automatic development-build payload/memo/auth/plaintext logging. `set_neutrino_diagnostics()` explicitly opts into immutable operation/stage/status metadata, with isolated handler failures.
- **Crypto regression coverage:** deterministic X25519 public-key/ECDH samples and RIPEMD-160 padding/offset cases agree with Node/OpenSSL; malformed X25519 lengths now reject. These supplement the existing SIV, ChaCha20-Poly1305 and signer checks.
- **Filters:** global/sticky RegExp filters no longer mutate caller lastIndex or alternate results across messages.

## Remaining findings, in priority order

1. **High — independent cryptographic/protocol qualification.** Differential samples do not establish formal constant-time properties or full adversarial correctness. Add independently generated Secret/Go transaction fixtures, broader fuzzing and live interoperability on an unfunded test setup. Consensus keys still rely on trusted transport/server identity, not remote attestation.
2. **Medium — durable notification recovery and backpressure.** SNIP-52 queues preserve order during a connection but have no durable cursor, backfill or seed-rotation policy. Duplicate retention covers only the most recent 1,024 successfully processed transaction identities. Slow callbacks can accumulate queued work; malformed authenticated CBOR requires recovery policy. Limits currently cap payloads at 1 MiB, work at 16,384 values and depth at 32. Indefinite-length CBOR and tags beyond 0–3 are explicitly unsupported; trailing padding is permitted by SNIP-52. Define configurable stream budgets/retry behavior and verify multi-node reconnects before calling this a reliable durable notification service.
3. **Medium — sequence coordination.** Account decoding is repaired, but simultaneous transactions can still choose the same sequence. Add an optional per-signer coordinator and distinguish chain rejection, timeout and unknown inclusion before retrying. Unknown custom account types require an explicit decoder instead of a permissive cast.
4. **Medium — cache freshness.** Client-scoped metadata has no TTL/invalidation for migration, key rotation or redirected chain identity. Existing handles retain their original code hash. Add refresh/invalidation, promise coalescing and verified chain identity.
5. **Medium — broader response/protocol coverage.** Query tuple optionality and response envelope checks are repaired; the suppression of the old tuple error is removed. Higher-level helpers reject missing/ambiguous object envelopes, and execute retains optional parsed JSON for raw results. Full contract-specific field validation, unknown/legacy message URLs and mixed-message nonce indexing still need fixtures and design work.
6. **Resolved locally — Contractor dependency advisory.** The revised Contractor/ts-morph graph removes the old braces path; the final Neutrino audit is clean. Splitting types from generator tooling remains an installation-size improvement, not a remaining advisory mitigation.
7. **Low — maintenance and release coverage.** Remove the commented cosmos-client module and stale docs; add minimum-Node/browser bundle-size CI. Validate padding configuration and public response sizes. Runtime metadata remains mutable. JavaScript cannot guarantee physical erasure of copied key material or JIT temporaries. The local cosmos-grpc dependency still needs a distinct upstream release and registry-clean package validation.
